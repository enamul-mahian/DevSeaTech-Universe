# Approved Visual Baseline — DevSeaTech Universe

Status: Owner-approved visual direction. Implementation must be reviewed against the original user-provided and generated mockups from the design discussion. This file captures the requirements, not the original image bytes.

## Naming and identity
- Product name everywhere: **DevSeaTech Universe**, not DevSeaTech Browser.
- Official DevSeaTech circuit/infinity brand mark, provided by the owner, must be used. Temporary glyphs and substitute logos are not final.
- English-only product UI and GitHub content. Chat discussion may use Banglish.

## Login (approved concept)
- 16:9 premium split layout, deep midnight-blue galaxy, mountains and subdued shooting stars.
- Left: official logo/wordmark, product features, contact panel (devseatech60@gmail.com, +8801805839123, www.devseatech.com).
- Right: neon-trimmed dark translucent glass login panel with prominent product name, Master Login, secure password field, show/hide, primary action, clear recovery.
- Dedicated options for 24-hour, 72-hour and administrator-defined trial hours and license activation **only when server-side functionality is implemented**. No deceptive functional placeholders.
- One Master Login gives access to all authorized profiles; separate admin authentication for settings. A forgotten-password production recovery flow requires strong verified ownership.
- Motion is subtle and performant; respect reduced-motion settings and provide accessible static fallback.

## Dashboard (approved concept)
- Consistent dark blue + cyan neon theme, professional restrained glassmorphism.
- Left sidebar: Profiles, Proxy, Automation (non-AI), Teams, Settings, Security, Billing; include other approved product modules where implemented.
- Header: profile search, notifications, theme selector, team/user menu.
- Central region: key profile metrics and a usable profile table with status, assigned proxy, groups, tags, notes, actions, and pagination.
- Digital globe/network and shooting-star background must never impede readability.
- Dark, Light/White and Auto modes; user/admin theme policy enforced. Editable branding and future admin-managed UI settings.
- Do not add AI Assistant or AI Hub. Android remains on hold.

## Design acceptance gates
1. Actual native UI screenshot comparison against approved references at 16:9 and common desktop resolutions.
2. Visual review of logo correctness, typography, spacing, contrast, responsive scaling and animations.
3. Accessibility checks (keyboard focus, contrast, reduced motion).
4. Verify real controls are functional and backed by authorization; mark unfinished functionality clearly.
5. Manual Windows preview testing before any final UI signoff.
6. No production readiness claim from image mockups alone.

## Delivery
Preserve screenshots and owner-approved binary artwork in a persistent asset location/repository with permission before claiming pixel-accurate matching. Design images in chat are references, not executable UI.
